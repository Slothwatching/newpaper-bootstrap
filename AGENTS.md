# Agent Instructions

- Keep public application code in this repository.
- For every user-requested change, add an entry to the sibling private `../newpaper-ops/INTENT_LOG.md` before marking the work complete.
- Record the user's request, why they want the change, the expected outcome or constraints, and a link to the related issue, pull request, or commit. Preserve the user's wording when it matters. If the reason is unclear, mark it as unknown and ask; do not invent a reason.
- Git history records the implementation. Do not repeat code diffs in the intent log.
- Never commit secrets, tokens, passwords, or customer data to either repository.
