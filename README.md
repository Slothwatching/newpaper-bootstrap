# newpaper

Public application repository. Clone it alongside the private `newpaper-ops` repository under the same parent directory.

Git history here shows what changed. For every user-requested change, record why the user wants it and the expected outcome in `../newpaper-ops/INTENT_LOG.md`, then link the related issue, pull request, or commit. Do not duplicate the code diff in the intent log or commit credentials or customer data to either repository.

Open `../newpaper-ops/newpaper.code-workspace` in VS Code to work with both repositories together.
