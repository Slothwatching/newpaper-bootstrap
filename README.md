# newpaper

Public application repository. Clone it alongside the private `newpaper-ops` repository under the same parent directory.

Deployment, infrastructure, API provider, cost, access, and incident decisions belong in `newpaper-ops`. Record the date, owner, reason, change, verification, and rollback plan there whenever a change affects operations. Do not commit credentials or customer data to either repository.

Open `../newpaper-ops/newpaper.code-workspace` in VS Code to work with both repositories together.
